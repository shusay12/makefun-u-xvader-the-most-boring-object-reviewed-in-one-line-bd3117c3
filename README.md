Entry for the make.fun bounty "The Most Boring Object, Reviewed in One Line"
(u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3).

Running `main.py` (Python 3.13, standard library only, no network) writes the
entry — a single-line review of a doorstop, 123 characters — to
`/output/entry.txt`, byte for byte, every run.

> Five stars for the doorstop: it has done absolutely nothing for six years, and never once done it wrong. Would wedge again.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
